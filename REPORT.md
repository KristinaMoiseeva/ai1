# Отчёт: ЛР1, вариант 4

## Задание

Вариант 4: выполнить **kNN (раздел 1)** и **softmax-классификатор (раздел 3)** на MNIST.

## Данные

MNIST, 28×28, 10 классов. В эксперименте использованы фиксированные стратифицированные подвыборки: 5000 train, 1000 validation, 1000 test.

## kNN

- реализованы расстояния с двумя циклами, одним циклом и без циклов;
- построена матрица расстояний test→train;
- исследована зависимость accuracy от `k`;
- `k` выбран по 5-fold CV только на train;
- лучшее `k = 3`;
- test accuracy: **0.9310 (93.1%)**.

## Softmax

- выполнено вычитание среднего train-изображения и добавлен bias-признак;
- реализованы naive и vectorized cross-entropy loss/gradient;
- аналитический градиент проверен численно;
- реализован mini-batch SGD;
- learning rate и L2 выбраны по validation;
- лучшие параметры: `learning_rate=0.1`, `reg=0.0001`;
- test accuracy: **0.8870 (88.7%)**.

## Вывод

На данном разбиении kNN показал более высокую точность, чем линейный softmax. Это ожидаемо для MNIST: kNN способен использовать локальную структуру выборки, тогда как softmax строит линейные границы классов. Test не использовался при выборе гиперпараметров.
